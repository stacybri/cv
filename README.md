## My pagedown rendered CV

This repo contains the source-code and results of my CV built with the [pagedown package](https://pagedown.rbind.io) and a modified version of the 'resume' template. Publications refresh themselves weekly from ORCID/OpenAlex via GitHub Actions — see `.github/workflows/update-cv.yml`.

The main files are:

- `resume.Rmd`: Source template for single page resume.
- `resume.html` / `resume.pdf`: Rendered outputs, regenerated automatically.
- `data/positions.csv`: Hand-maintained education, positions, and teaching entries. A column `section` tells the template which rows go where.
- `data/publications_auto.csv`: Publications, regenerated by `scripts/fetch_publications.R` from ORCID + OpenAlex — don't hand-edit, it gets overwritten.
- `data/citations_by_year_auto.csv`: Aggregate citation counts by year, feeding the "Citations" chart. Also regenerated by `scripts/fetch_publications.R`.
- `scripts/fetch_publications.R`: Pulls publications/citations from ORCID + OpenAlex.
- `scripts/render_cv.R`: Renders `resume.Rmd` to `resume.html` and `resume.pdf`.
- `css/`: Directory containing the custom CSS files used to tweak the default 'resume' format from pagedown.

## Want to use this to build your own CV/resume? 

1. Fork, clone, download the zip of this repo to your machine with RStudio.
2. Go through and personalize the supplementary text in the Rmd you desire (`index.Rmd` for CV, `resume.Rmd` for resume).
3. Replace your ORCID iD in `scripts/fetch_publications.R`, and replace the rows of `data/positions.csv` with your own education/positions.
4. Print each unique `section` (as encoded in the `section` column) in your `.Rmd` with the command `position_data %>% print_section('education')`.
